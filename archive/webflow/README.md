# Webflow archive

Captured from the published `https://xander.ai` site on 16 August 2026.

- `sitemap.xml` is the published Webflow sitemap.
- `robots.txt` is the published robots file.
- `pages/` contains the raw HTML retained from the migration: one homepage and 14 essays.
- The media referenced by those pages was downloaded into `src/assets/` as part of the import.

Webflow's Designer code-export dialog reported that code export requires a paid Workspace plan, so this archive was produced from the published site instead. It preserves the public site but does not include the unpublished drafts visible in Designer.
